📐 设计说明

山坡地图后台送礼视图

一、这是什么站

「云雾峰茶园认养」演示一座山坡茶园的地块—认养—采摘—检测全链路。核心难点不是展示，而是地块边界会随时间变化（排水沟扩建要拆分、田块整合要合并、复测要纠偏），而认养合同跨在这些变化的前后。本站把「空间几何」「时间版本」「认养权利」三者的关系做成可验证的系统，而不是静态宣传页。

技术：Node.js 内置 http + better-sqlite3（同步事务）+ 原生 HTML/CSS/JS + 自研 SVG 地图与平面几何算法，无前端框架、无第三方地图依赖。

二、空间版本模型（用户怎么看懂"这是哪个时段"）

  • parcels 是地块逻辑实体（拆分时延续片保留同一 id）；parcel_versions 保存每一条边界版本：GeoJSON 多边形、面积、半开有效区间 [valid_from, valid_to)、当时编码/名称快照。
  • 地图顶部有时段滑块（2023–2026）。页面任何时刻都显示一个明确日期，并在标题用色块标注「查看时段」；详情与认养区间都只取与该日期重叠的记录。
  • 旧认养按原边界保留在历史版本上：滑块拨回 2024-02 能看到整块老区 A 与何老伯的 3000㎡；拨到 2024-04 则是拆分后的 A1/A2 与按交集落下的 1350/1650㎡。
  • version_lineage 记录 create/split/merge/correct 及新旧版本交集权重，地块详情可查看完整谱系。

三、拆分/合并如何不重复分配面积

演化在单个数据库事务内完成：条件校验 → 关闭旧版本 → 写新版本 → 谱系 → 认养面积对应 → 占用校验，任一步失败整体回滚。

  1. 面积对应：旧版本上仍生效的每条认养，按 认养份额 f = 认养面积/旧面积 与新旧多边形几何交集，把面积分到新版本：confirmed = f × 交集面积。拆分矩形地块时严格等于按切线比例分配。
  2. 固定份额 fixed：合同面积不变。新边界能对应多少先确认多少，不足部分（>0.5㎡）记一条 pending 未决差异，在后台「未决差异」里人工"确认落实/核销"，不会悄悄多占。
  3. 随边界 boundary：权利随地面走，确认面积按交集自动重算，不挂未决。两种模式可在新增认养时直接比较。
  4. 不变量：每个地块版本在任意日期的 confirmed 认养面积之和 ≤ 版本面积（事件点扫掠求最大占用）。新增重叠认养或差异确认一旦超额，返回 409 AREA_CONFLICT。
  5. 合并只允许不重叠且并集为凸（凸包面积≈面积和）的地块，防止吞缝/自交；拆分要求切割线贯穿且两片面积之和等于原面积。

四、版本条件提交与并发占用冲突

  • 所有演化/认养写入都带 expectedVersion（乐观锁）。基于过期版本提交 → 409 STALE_VERSION，响应里附当前版本号，提示刷新重试。
  • better-sqlite3 同步事务 + busy_timeout，在 Node 单进程内把"读当前版本—改边界—校验占用—提交"做成串行临界区；真正的面积超额由事务末尾的占用断言兜底，而不是靠按钮置灰。
  • 所有登录、写入、冲突在 audit_log 留痕，后台「冲突审计」可查。

五、采摘批次与检测：只代表声明范围

  • 批次创建时绑定采摘当天生效的边界版本与手写「声明范围」（如"仅 A1 西片当日手采 42kg"）。
  • 检测报告挂在批次下；列表只显示数量，必须进入该批次详情才能看到检测内容与"仅对该批次来样负责"的醒目声明。任何页面都不出现"全园农残合格"之类的泛化表述。
  • 撤回检测 = 报告软撤回 + 附件在对象层 archived 归档：文件以 SHA-256 命名存于 data/objects/，DB 仅存指针/哈希；归档后下载接口返回 410，文件不物理删除以留痕。

六、送礼视图：权限在接口，不靠 CSS

分享链接是服务端签发的随机令牌（gift_shares，可过期、可撤销）。GET /api/gift/:token 在服务端按 scope 组装响应：

  • gift：只返回署名、地块、面积、时段——JSON 里根本不存在 priceCents/contact 字段；
  • admin：才额外下发价格与联系方式；
  • 过期 → 410、撤销 → 404，前端拿不到任何认养数据。可在浏览器直接打开接口 URL 验证"看不到"，而不是检查元素找隐藏 DOM。

七、离线生长日记

农户断网写日记 → 写入 localStorage 待发队列（含 clientId）；联网后自动 POST 同步。服务端对 client_id 建唯一约束并幂等去重：重复/重试提交只保留一条，已同步的会返回 deduplicated。Service Worker 只缓存应用外壳，绝不缓存 API 写请求，避免"断网假成功"。

八、地图与视觉（原创）

  • 手绘风等高线 + 纸感卡片 + 山雾绿/茶汤赭配色，斜纹叠加表达已认养占比，超额地块变红；指北针、50m 比例尺与"局部米制坐标、非地理投影"声明，避免用户误把示意图当 GIS 定位。
  • 每个地块标签同时给出 版本号 + 面积 + 已认面积；认养条目显示署名、模式徽标、区间与待决状态，让"位置属于哪个时段、记录属于哪份合同"一目了然。
